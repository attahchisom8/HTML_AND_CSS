Welcome to Mastermose Tech

1. Quick Capture:
Type your task at the bottom. Optionally click the priority !! button or the calendar icon 📅 to add a deadline, then hit "Add Task".

2. Automated Workspaces:
Use the workspace menu to switch contexts. Any task you create is instantly saved directly inside the workspace you are currently looking at!

3. Keep an Eye on Priorities:
Tasks are clearly marked by urgency. Don't let your high-priority items sit uncompleted for too long!

4. Task Management:
Use the actions column to edit details, pause items, or smash the delete icon to clear completed work.
